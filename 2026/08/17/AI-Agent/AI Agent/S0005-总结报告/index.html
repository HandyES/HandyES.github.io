二、技术选型决策矩阵

2.1 推理架构选型

场景 推荐架构 理由 涉及课程
简单单步任务 ReAct Thought-Action-Observation循环足够，延迟低 第03课
复杂多步任务 Plan-and-Execute 先规划DAG再执行，避免中途偏离 第03课
需要自我改进 ReAct + Reflexion 反思记忆驱动迭代改进 第03课
需要探索多种策略 ToT规划 + ReAct执行 ToT选路径，ReAct走路径 第03/04课

2.2 上下文管理选型

场景 推荐策略 理由 涉及课程
工具数量少（<5） 全量注册到tools参数 Token开销可控，选择准确率高 第04/05课
工具数量多（>5） Skills按需加载 避免工具过多降低选择准确率 第04课
长对话 滑动窗口+摘要压缩 控制Token预算，保留关键信息 第04课
需要结构化输出 Constrained Decoding 格式保证，无需应用层解析 第04课
需要工具调用 Function Calling（非Prompt层） API原生支持，格式保证 第05课
